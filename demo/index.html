ms-Dropdown Demo

A JavaScript library for converting HTML select elements into enhanced image-based dropdowns.

Basic Example

<select id="basic" class="ms-dropdown">
    <option value="facebook">Facebook</option>
    <option value="twitter">Twitter</option>
    <option value="linkedin">LinkedIn</option>
    <option value="instagram">Instagram</option>
</select>

With Images

<select id="with-images" class="ms-dropdown">
    <option value="facebook" data-image="../dist/images/icons/facebook.png">Facebook</option>
    <option value="twitter" data-image="../dist/images/icons/twitter.png">Twitter</option>
    <option value="linkedin" data-image="../dist/images/icons/linkedin.png">LinkedIn</option>
    <option value="instagram" data-image="../dist/images/icons/instagram.png">Instagram</option>
</select>
